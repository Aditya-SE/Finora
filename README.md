# Finora

Finora is a full-stack project created to practice and improve my React development skills while building a stock trading platform.

## 🚀 Live Demo

**[https://finora-frontend-d720.onrender.com/](https://finora-frontend-d720.onrender.com/)**

## 🛠️ Technologies Used

- React.js
- Material UI (MUI)
- Node.js
- Express.js
- MongoDB
- JavaScript
- HTML
- CSS
- Bootstrap

## ✨ Features

- User Signup & Login
- Trading Dashboard
- Buy & Sell Actions
- Portfolio Management
- MongoDB Database
- Responsive Design
- Modern UI with Material UI
