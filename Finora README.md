# Finora

Finora is a full-stack stock trading and investment platform built for managing and exploring trading activities through a modern web interface.

## 🚀 Live Demo

**[https://finora-frontend-d720.onrender.com/](https://finora-frontend-d720.onrender.com/)**

## 🛠️ Technologies Used

- React.js
- Material UI (MUI)
- Node.js
- Express.js
- MongoDB
- JavaScript
- HTML
- CSS
- Bootstrap

## ✨ Features

- User Signup & Login
- Trading Dashboard
- Buy & Sell Actions
- Portfolio Management
- MongoDB Database
- Backend API Integration
- Responsive Design
- Modern UI with Material UI
